# 晓点滴｜校园经历与校园故事分享

个人校园经历、课堂见闻、宿舍生活、社团活动、考试复盘、四六级准备、学生优惠、省钱折扣、校园日常和毕业回忆。

## 打开方式

```text
python -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

## 文章结构规范

每篇文章由以下部分组成：

```
{
  "id": 编号,
  "title": "标题",
  "category": "分类",
  "date": "发布日期",
  "summary": "摘要（1-2句话）",
  "content": ["段落1", "段落2", ...],
  "practical": {
    "audience": ["适合谁看1", "适合谁看2"],
    "takeaway": "一句话核心收获",
    "checklist": ["可执行步骤1", "可执行步骤2", ...],
    "pitfalls": ["避坑提醒1", "避坑提醒2", ...]
  },
  "weight": 权重分数,
  "keywords": [...],
  "searchKeywords": [...]
}
```

### practical 编写原则

practical 是每篇文章的实用信息区，必须与文章主题直接相关：

- **audience**：写清楚谁会需要这篇文章，不要写无关人群
- **takeaway**：一句话总结这篇文章能解决什么问题，必须针对文章具体主题
- **checklist**：列出读者看完文章后可以直接执行的步骤，步骤要具体到能照做
- **pitfalls**：列出与文章主题相关的常见错误或陷阱

**禁止**：practical 内容与文章主题无关（如食堂文章的 checklist 写考试复习步骤）。

## 性能与 SEO

- 首屏脚本 `defer`，CSS `preload` 后加载。
- 首页默认展示 6 条目录，保留精选与最新入口。
- 文章页含阅读时长、目录锚点、相关推荐和 `BlogPosting` 结构化数据。
- 生产环境建议开启 Brotli/gzip。
