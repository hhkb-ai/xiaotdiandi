# Python学习主页

> [!info] 学习目标
> 用 30 天建立 Python 基础：每天学习一个语法点、一个符号或操作符用法，并完成一个小练习。

## 导航

- [[Python学习资料]]
- [[Python每日学习计划]]
- [[Python语法与符号速查]]
- [[Python每日复盘模板]]

## 每日学习流程

1. 阅读当天的语法点。
2. 理解当天的符号或操作符。
3. 手写 3 到 5 行示例代码。
4. 完成当天小练习。
5. 用 [[Python每日复盘模板]] 记录一个易错点。

## 环境建议

- 安装 Python 3.12 或更新版本。
- 编辑器可用 VS Code、PyCharm 或 Obsidian 里的代码块记录。
- 每天新建一个练习文件，例如 `day01_variables.py`。

> [!tip]
> 不要只看资料。每个语法点至少敲一遍、改一个变量、故意制造一次错误，再看报错信息。
