- 四六级考试网址 cet.neea.edu.cn

- 《社会保险法》相关规定
- GitHub Student Developer Pack 网址
- 苹果序列号查询网址

### 需改写（金额/日期/比例可能过期）

- 四六级报名时间 → 改为"具体以各高校教务处通知为准"
- 考研初试时间 → 改为"具体以教育部公告为准"
- 推免系统填报时间 → 改为"具体以研招网公告为准"
- 五险一金缴纳比例 → 改为"因地区而异，以当地规定为准"
- 学生票优惠比例 → 改为"以 12306 官网最新政策为准"
- 海底捞折扣 → 改为"以门店实际政策为准"
- 苹果返校季赠品 → 删除具体赠品信息

### 需删除（无法验证或可能误导）

- 三方协议违约金"通常在 3000 到 5000 元"
- 苹果返校季"通常还会额外赠送 AirPods 或 Apple Pencil"

- 《学位论文作假行为处理办法》第 34 号令
- 《参考文献著录规则》GB/T 7714-2015

## 总结

1. **大部分法律条款引用准确**，可保留
2. **具体金额和日期需要改为模糊表达**，避免过期
3. **优惠折扣信息需要注明"以官方最新政策为准"**
4. **部分法律依据需要补充具体文件编号**
5. **建议每季度检查一次优惠和政策信息的时效性**
