# 03_用户行为与体验分析

## 文件夹用途

聚焦用户群体特征、浏览路径、搜索行为和交互反馈，定位用户体验痛点。

## 子文件夹

- `用户画像分析`：整理用户地域、年龄层、设备、访问时段等信息。
- `行为路径分析`：统计入口页、出口页、浏览路径、停留时长和跳转率。
- `交互行为数据`：分析搜索、分类、卡片点击、订阅、分享等行为。
- `体验问题反馈`：归档用户反馈、排版问题、操作卡顿、功能异常。

## 第 3-4 周更新计划

1. 建立核心用户画像：大学生、新生、应届生、校园生活内容搜索用户。
2. 分析用户从首页搜索、分类、卡片进入详情页的路径。
3. 记录搜索失败词和低点击内容。
4. 输出《用户行为与体验分析报告》。

## 当前重点观察

- 搜索框是否足够明显。
- 模糊搜索是否返回准确结果。
- 首页内容是否过多。
- 分类是否能让用户快速找到学习、就业、安全、校园日常内容。
- 移动端阅读是否舒服。
