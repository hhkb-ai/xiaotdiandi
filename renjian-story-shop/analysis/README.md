# 晓点滴网站分析工作台

本目录按《晓点滴网站分析工作更新计划（文件夹版）》落地，用于持续跟踪网站体验、内容效果、用户行为、技术性能和后续迭代。

## 工作目标

- 明确网站分析范围和指标口径。
- 建立访问、内容、交互、性能四类数据的采集与归档方式。
- 定期发现网站问题，形成可执行优化方案。
- 记录优化前后数据变化，持续复盘。

## 目录结构

| 文件夹 | 用途 | 更新频率 |
| --- | --- | --- |
| `01_前期筹备与需求规划` | 分析目标、指标体系、排期、参考资料 | 阶段性更新 |
| `02_数据采集与基础分析` | 原始数据、清洗数据、基础报表、可视化说明 | 每周更新 |
| `03_用户行为与体验分析` | 用户画像、浏览路径、交互行为、体验反馈 | 每两周更新 |
| `04_内容运营与效果分析` | 内容热度、分类效果、投稿/更新、内容建议 | 每周到每月更新 |
| `05_问题诊断与优化方案` | 问题清单、根因分析、优化方案、落地排期 | 每次优化前后更新 |
| `06_分析报告与成果归档` | 正式报告、摘要、素材、参考资料 | 阶段性归档 |
| `07_迭代跟踪与复盘总结` | 优化效果监控、进度跟踪、月度/季度复盘 | 长期持续 |

## 核心监控方向

1. 用户体验：搜索是否好用、分类是否清晰、文章阅读是否顺畅、移动端是否可用。
2. 内容热度：哪些校园故事、学习知识、就业入门和实用清单更容易被阅读。
3. 技术性能：首页加载、资源体积、脚本错误、移动端布局稳定性。
4. SEO 效果：搜索入口、长尾关键词、页面标题和描述覆盖度。
5. 迭代效果：优化前后数据变化、问题是否复现、内容更新是否带来更多访问。

## 命名规范

所有新增分析文件建议使用：

```text
YYYYMMDD_内容名称_V版本号.md
```

示例：

```text
20260511_用户画像分析_V1.0.md
20260511_首页体验问题清单_V1.0.md
20260511_内容热度周报_V1.0.md
```

## 更新节奏

- 基础数据、内容热度、优化效果：每周更新。
- 用户画像、行为路径、体验反馈：每两周更新。
- 总结报告、问题诊断、优化方案：阶段性更新。
- 复盘总结：每月小结，每季度完整复盘。

## 使用原则

- 记录结论时必须写清数据来源、统计范围和更新时间。
- 问题清单必须带优先级、影响范围、责任模块和验收标准。
- 内容建议必须回到网站主题：个人校园经历、校园故事与学生生活记录。
- 不在文档中暴露本地路径、内网地址、账号、Token、邮箱等敏感信息。
