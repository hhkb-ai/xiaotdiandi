🔧 主要修复内容

✅ 1. 返回逻辑修复

修改了返回按钮的行为，现在会优先返回上一页，而不是总是跳转到首页。

❌ 修改前

总是跳转到首页：router.push('/')

✅ 修改后

智能返回：router.back() 或首页

✅ 2. 文章内容排版优化

添加了智能的 Markdown 解析器，可以识别中文列表格式并转换为结构化内容。

  • 支持 Markdown 标题（# ## ###）
  • 支持粗体和斜体
  • 自动识别"第一，xxx；第二，xxx；第三，xxx"格式并转换为列表
  • 识别"先做哪三步：..."、"常见坑：..."、"详细步骤：..."等模式

✅ 3. 目录生成优化

改进了目录标题生成逻辑，提取更有意义的标题。

❌ 修改前

✅ 修改后

"先做哪三步"、"详细步骤"、"常见坑"

✅ 4. 添加 FAQ 展示

现在会展示文章中的常见问题解答，使用可折叠的详情组件。

✅ 5. 样式优化

优化了移动端字体大小、行高和响应式布局，提升阅读体验。

选课避坑：大二才知道的三个技巧

选课不只是选老师，更是选时间、选节奏、选期末压力。提前看培养方案、平衡学分难度、抢课设闹钟，三步就能避开大部分选课坑。

先做哪三步

  1. 开学前登录教务系统看培养方案，把必修、选修、通识课的学分要求列出来
  2. 把下学期要选的课按难度分三档（难、中、易），每学期保证难易搭配
  3. 热门课提前加入收藏，选课开放后第一时间操作

详细步骤

第一步，看培养方案。每个专业的培养方案在教务系统里都能查到，上面列清楚了毕业需要的总学分、必修课学分、选修课学分、通识课学分，以及哪些课有先修要求。

常见坑

  • 忽略先修要求。有些课必须先修完前置课程才能选，不看清楚选了也白选
  • 把所有硬课集中在一个学期。期末周会非常痛苦，成绩也可能不理想
  • 错过选课时间。热门课几分钟就满，不设闹钟大概率选不上

常见问题 FAQ

选课一般什么时候开始？
各校安排不同，通常在开学前一到两周开放选课。具体时间以本校教务处通知为准。
没选上热门课怎么办？
关注补退选阶段，通常开学第一周会有同学退课腾出位置。
选课学分有上限吗？
多数学校每学期有学分上限（通常 25 到 30 学分），具体以本校教务处规定为准。

💻 如何测试

在你的本地环境中运行以下命令：

# 进入项目目录
cd blog-vue

# 安装依赖（如果还没有安装）
npm install

# 启动开发服务器
npm run dev

# 打开浏览器访问 http://localhost:5173

然后点击任意文章查看详情页，测试返回按钮和内容排版效果。
