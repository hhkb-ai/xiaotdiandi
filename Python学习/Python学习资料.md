## 入门路线

1. 基础语法：变量、数据类型、条件、循环、函数。
2. 容器类型：列表、元组、字典、集合。
3. 文件与异常：读写文件、处理报错。
4. 模块与包：导入模块、安装第三方库、组织代码。
5. 面向对象：类、对象、方法、继承。
6. 小项目：命令行工具、数据处理脚本、简单网页请求。

## 推荐练习方式

- 每个知识点写一个最小示例。
- 每天记录一个错误信息和解决方法。
- 每周做一个小项目，不追求大，只追求能运行。

## 常用命令

```powershell
python --version
python hello.py
python -m pip install requests
python -m venv .venv
```
