# 02_数据采集与基础分析

## 文件夹用途

负责收集、清洗、整理网站运行数据，形成基础统计和可视化说明，为用户体验、内容运营和问题诊断提供依据。

## 子文件夹

- `原始数据备份`：保存访问数据、用户行为数据、内容浏览数据、性能日志原始文件。
- `数据清洗处理`：保存清洗后的标准化数据，标注来源和时间范围。
- `基础数据统计`：保存日、周、月访问量、页面加载速度、设备分布等报表。
- `数据可视化图表`：保存图表说明、截图或生成图表的数据源。

## 第 2-3 周更新计划

1. 搭建数据采集渠道，记录现有本地事件字段。
2. 回溯最近 30 天可用数据。
3. 按周生成基础数据统计。
4. 输出《基础数据分析简报》。

## 当前可采集事件

当前前端已在本地浏览器记录部分事件，存储键为 `xiaodid_metrics`：

- `story_open`
- `story_open_url`
- `search_input`
- `filter_category`
- `sort_change`
- `keyword_click`
- `toggle_archive`
- `subscribe_local`
- `web_vital_lcp`
- `web_vital_cls`

说明：当前为静态站点，本地事件不自动上传服务器。正式统计需要接入 Plausible、Fathom、GA4 或服务端日志。
