# 04_内容运营与效果分析

## 文件夹用途

分析网站内容热度、分类效果、用户偏好和内容缺口，指导后续内容更新方向。

## 子文件夹

- `内容热度排行`：统计文章阅读量、点击量、收藏或分享等热度数据。
- `内容分类分析`：分析校园日常、学习知识、就业入门、实用清单、安全情绪等板块效果。
- `投稿数据统计`：记录投稿数量、审核通过率、优质投稿占比。
- `内容优化建议`：基于数据提出新增、删减、改写和 SEO 优化方向。

## 第 4-5 周更新计划

1. 建立内容热度周榜。
2. 分析各分类流量占比和搜索进入情况。
3. 找出缺内容、低停留、高跳出板块。
4. 输出《内容运营效果分析报告》。

## 内容判断原则

新增或优化内容必须符合网站主题：

> 个人校园经历、校园故事与学生生活记录。

就业、AI、学生优惠、省钱、安全等内容可以加入，但必须从大学生实际场景出发。
